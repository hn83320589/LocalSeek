# 範例語料的逐步手算結果

語料在 [`samples/corpus`](../corpus)。以下的詞元、tf、df、len 皆依假設事項的分詞規則**人工推導**；
只有最後的算術（ln 與除法）用計算機完成。測試 `SampleCorpusTests` 驗證引擎結果與本表一致（相對誤差 ≤ 1e-9）。

## 1. 文件、詞元與長度

公式：idf = ln(1 + (N − df + 0.5) / (df + 0.5))；score = Σ idf × tf × 2.2 / (tf + 1.2 × (0.25 + 0.75 × len / avgdl))
